# **App Name**: CNPJ Insights

## Core Features:

- CNPJ Input: Allows the user to input a CNPJ number via a text field.
- Data Fetching: Fetches company data from the Receita Federal (Brazilian IRS) database using the provided CNPJ.
- Data Display: Displays the retrieved company data in a clear and organized manner.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to convey trust and reliability, in line with handling official data.
- Background color: Light blue-gray (#ECEFF1), offering a clean and unobtrusive backdrop.
- Accent color: Soft orange (#FFAB40), used sparingly for interactive elements to add a touch of vibrancy without distracting from the core data presentation.
- Font pairing: 'Inter' (sans-serif) for body and headline. A clean, neutral sans-serif ensures readability.
