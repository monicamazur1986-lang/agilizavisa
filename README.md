# AgilizaVISA – PARANÁ

ESTA É UMA APLICAÇÃO NEXT.JS DE ALTA PERFORMANCE PARA CONSULTA DA CLASSIFICAÇÃO DE RISCO SANITÁRIO DE EMPRESAS BRASILEIRAS COM BASE NO CNPJ.

## LEGISLAÇÃO APLICADA
- RESOLUÇÃO SESA Nº 1034/2020
- DECRETO ESTADUAL Nº 10.590/2025
- LEI DE LIBERDADE ECONÔMICA (LEI Nº 13.874/2019)

## CARACTERÍSTICAS TÉCNICAS
- **MARCA**: AgilizaVISA (Agiliza + VISA institucional).
- **LINGUAGENS**: TypeScript (Lógica), Tailwind CSS (Design), React (Interface).
- **FRAMEWORK**: Next.js 15 (Arquitetura de Alta Performance).
- **BACKEND**: Firebase Firestore (Cache Inteligente e Auditoria).
- **MOTOR DE ANÁLISE**: NORMALIZAÇÃO NUMÉRICA UNIVERSAL DE 7 DÍGITOS.
- **IDENTIFICAÇÃO O(1)**: MAPA DE LOOKUP DE ALTA PERFORMANCE.
- **RESILIÊNCIA**: ESCUDO DE HIDRATAÇÃO PARA FIREBASE EM AMBIENTE SSR.
- **PADRÃO VISUAL**: RIGOR TÉCNICO E CAIXA ALTA MANDATÓRIA (SALVO LOGOTIPO).

O Agiliza Visa é um projeto desenvolvido sem qualquer finalidade comercial ou lucrativa.
SISTEMA OPERACIONAL E HOMOLOGADO EM CONFORMIDADE COM A LEGISLAÇÃO ESTADUAL VIGENTE.
